# 패치 노트

---

## 로그아웃 버튼

- **모든 탭에서 로그아웃 버튼 표시**
  - 대시보드, 웹훅 관리, 메시지 관리 화면 상단 네비게이션에 로그아웃 버튼과 사용자 이메일을 동일하게 노출하도록 수정했습니다.

---

## 반복 주기

- **평일 / 주말 옵션 추가**
  - 반복 주기 선택지에 **평일**(월~금), **주말**(토·일)을 추가했습니다.
  - 매일과 같이 선택 시 해당 요일이 자동으로 적용됩니다.
  - 백엔드: `repeatCycle`에 `weekdays`, `weekend` 지원 및 스케줄러/라우터 반영.

---

## 메시지 입력 UI

- **메시지 내용 textarea 자동 확장**
  - 입력·붙여넣기 시 내용 길이에 따라 textarea 높이가 자동으로 늘어나도록 했습니다.
  - AI로 한 번에 내용을 채울 때도 동일하게 확장되며, 모달을 열 때 기존 내용이 있으면 높이가 맞춰집니다.
  - 최소 높이 100px, `resize-none`, `overflow-y-auto` 적용.

---

## 메시지 관리 리스트

- **활성/비활성 토글**
  - 활성/비활성 전환을 텍스트 버튼에서 **스위치 토글** 형태로 변경했습니다.
  - 토글 위치를 **메시지 박스 우측 하단**으로 고정했습니다.
  - 비활성일 때 원(thumb) 위치를 왼쪽으로 조정(`translate-x-0.5`)했습니다.

- **액션 버튼 아이콘화**
  - **즉시 전송**, **수정**, **삭제**를 텍스트 버튼에서 아이콘 버튼으로 변경했습니다.
  - 각각 전송(비행기), 연필(수정), 휴지통(삭제) 아이콘과 `title` 툴팁을 사용합니다.

- **토글 시 화면 유지**
  - 토글 클릭 시 `updateMessage`만 호출하고 전역 `loading`을 설정하지 않도록 해, 목록이 사라졌다가 다시 나타나는 현상을 제거했습니다.

- **제목(내용) 글자 수 제한 표시**
  - 리스트에서 메시지 내용을 **30자**까지만 보여주고, 초과 분은 말줄임표(…)로 표시하도록 했습니다.

## AI 기능

- **특정 시간대 반복 반영**
  - AI 프롬프트에 "특정 시간 반복"(예: 09:00~18:00, N분마다) 관련 내용이 포함되면, 응답의 `timeRangeStart`, `timeRangeEnd`, `intervalSeconds`를 파싱해 폼에 자동 반영합니다.
  - 백엔드: `AI_SYSTEM_PROMPT`에 해당 JSON 필드 설명 추가, `MessageAIGenerateResponse` 및 파싱·검증 로직 추가.
  - 프론트: AI 적용 시 `useTimeRangeMode`와 시작/종료 시간, 간격(시/분/초) 입력란을 채우도록 처리했습니다.
